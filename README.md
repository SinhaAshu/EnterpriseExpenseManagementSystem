# 💰 Expense Management System

A full-stack web application to manage employee expenses with role-based access, approval workflows. Built using **Spring Boot**, **React**, **MySQL**, and **JWT authentication**.

---

## 🚀 Features

- 🧾 Add and manage expenses
- 🔒 Role-based access for Admin, Manager, and Employee
- 📂 File upload for invoices
- ✅ Expense approval/rejection by manager/admin
- 🔐 Secure login with JWT authentication
- 🧑 User profile update (email/password/full name)

---

## 🛠️ Tech Stack

**Frontend**:  
- React.js  
- Axios  
- React Router  
- React Toastify  

**Backend**:  
- Java  
- Spring Boot  
- Spring Security  
- JWT  
- Hibernate & JPA  
- MySQL

**Tools**:  
- Postman (API testing)  
- VS Code & EclipseIDE 
- Git & GitHub  
---

## 🧩 Modules

- **Authentication Module**: Secure login, JWT, role-based access
- **Expense Module**: Add, view, filter expenses
- **Approval Module**: Manager/Admin approve or reject expenses
- **Employee Module**: Add, update, delete(only by admin)
